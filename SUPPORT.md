# Getting help

- **Questions and ideas:** [GitHub Discussions](https://github.com/alethialabs-io/alethialabs/discussions) on the main repository.
- **Bugs:** open an issue on [alethialabs-io/alethialabs](https://github.com/alethialabs-io/alethialabs/issues/new/choose), including for the CLI, the starters and the examples.
- **Docs:** https://alethialabs.io/docs, including [troubleshooting](https://alethialabs.io/docs/troubleshooting).
- **Security issues:** never in a public issue. Email security@alethialabs.io, as [SECURITY.md](SECURITY.md) describes.
